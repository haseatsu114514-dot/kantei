# kantei

ステラファイルの個別鑑定文を作るための、鑑定スタイル・文章ルール・AI向けコンテキストの正本です。

## AIが最初に読むもの

1. [docs/READING_STYLE_CONTEXT.md](docs/READING_STYLE_CONTEXT.md)
2. 案件ごとの入力情報・相談内容
3. 必要に応じて stellafile / koukaitool の関連仕様

`docs/READING_STYLE_CONTEXT.md` には以下をまとめています。

- 鑑定の基本姿勢
- 一人称・二人称
- 専門用語の扱い
- AI臭さを減らす文章ルール
- 括弧・カギ括弧・語尾・段落・改行
- ステラファイル固有語
- 現行10キャラ
- ギフト名とモチーフ
- 相性表現
- 個別鑑定の基本構成
- 出力前のセルフチェック

鑑定文の生成・修正では、このコンテキストを最優先で参照します。
